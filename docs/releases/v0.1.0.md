# OpenCCForSigil 0.1.0

This release connects the V1 conversion workflow, rules and profiles, document
metadata options, and private reports, and strengthens cross-platform packaging.

## Install

Download **OpenCCForSigil_0.1.0.zip** from this release and install it through
Sigil's plugin manager. GitHub's source archives are not installable plugin
packages. When updating, replace the previous plugin through Sigil; preferences,
rules, profiles, and history are stored outside the plugin directory and EPUB.

The Fat Plugin includes CPython 3.14/cp314 payloads for Windows x86_64, Linux
x86_64, macOS Intel, and macOS Apple Silicon. Other Python minor versions and
Windows/Linux ARM are not included. The native Jieba build is constrained to
macOS 13 and Linux GLIBC 2.35 / GLIBCXX 3.4.30 or earlier symbol requirements.

## Changes

- Optional Jieba loading no longer blocks standard conversion. Selected Jieba
  configurations never silently fall back, and integrity failures remain blocking.
- Bound long-text diff work, move analysis to a worker-owned backend, and add
  cooperative cancellation without writing a partial plan.
- Add opt-in NCX labels, whitelisted OPF metadata, and grouped updates to existing
  Chinese language tags while preserving source formatting outside planned patches.
- Add locked exact/protect rules, profile and book scopes, rule import/export,
  a sandbox, and independent official-config comparisons.
- Add optional quotation and horizontal-punctuation transforms, mixed-script
  diagnostics, and explicit high-risk pivot and numeric Han reference options.
- Add spine scope, preview filters and grouped decisions, return to settings,
  Checkpoint reminders, and source/rule/profile checks before applying.
- Add private history and Markdown/JSON reports. Persisted history excludes book
  text; exporting a full diff requires an explicit choice.

## Validation and remaining acceptance

The release pipeline runs repository tests and official OpenCC/CLI differential
checks on all four native runners, then validates the final ZIP's complete
runtime matrix, provenance, hashes, and native binary baselines. The differential
corpora contain 28 standard and 10 native Jieba cases. Local validation also
covered controlled UI actions using Sigil's bundled macOS Qt runtime.

These checks do not constitute installation, apply, save, and reopen acceptance
on all four real Sigil hosts, or execution on the oldest supported OS versions.
Previous user acceptance applies to the previously tested package. Minor UI
polish already noted remains deferred; this release needs its own real-book
acceptance. Use Sigil's Checkpoint or a backup before applying book-wide changes.

See [implementation choices and acceptance boundaries](https://github.com/liyafly/OpenCCForSigil/blob/v0.1.0/docs/deviations.md)
and the [changelog](https://github.com/liyafly/OpenCCForSigil/blob/v0.1.0/CHANGELOG.md).
