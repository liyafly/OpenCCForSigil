## Changes

- Report cross-ruleset conflicts before analysis and preserve selected rulesets
  across renames and confirmation flows.
- Improve TSV, CSV, TXT, and JSON rule import and export, including header
  detection, owner selection, Unicode line handling, and V2 rule preservation.
- Simplify conversion setup and rule controls; apply one scope precedence and
  derive NAV conversion from the selected file set.
- Improve responsiveness for large previews with filtered group updates and
  batched decisions.
- Keep regex timeouts per call while applying hit and output limits per text
  fragment, and aggregate zero-width diagnostics by rule and file.
- Reduce language-tag choices to keeping existing tags or updating Chinese
  tags, while retaining legacy saved-profile behavior.

## Automated validation

The release candidate passed the local repository gate. The tagged workflow
builds and validates the Fat Plugin and six platform packages, runs all six
runtime smoke jobs, verifies package checksums, and attests release assets
before publishing.

## Remaining acceptance

Installation, conversion, save, and reopen in a real Sigil host have not been
tested for this version. Host acceptance remains **Not verified**.
