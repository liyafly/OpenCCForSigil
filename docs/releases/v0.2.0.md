CPython ABI used by Sigil's plugin process. GitHub's automatically generated
source archives are not installable plugins.

Choose the Linux package whose CPython ABI matches Sigil's plugin process.
The standard Linux packages require CPython 3.14/cp314; the separate x86_64
package requires CPython 3.12/cp312. The Fat Plugin contains the five cp314
payloads and does not include the cp312 runtime.

## Changes

- Prevent preview decisions from splitting phrase-level OpenCC conversions.
- Preserve protected XHTML and source text, and report malformed source files
  with precise diagnostics while allowing unrelated files to proceed.
- Improve settings, profiles, rules, history, progress, preview, and result
  dialogs, with localized controls and clearer failure and discard feedback.
- Reduce repeated work and refresh large previews incrementally.
- Add Linux x86_64/cp312 packaging; add cross-platform Jieba consistency checks
  and attestations for the release assets.

## Automated validation

The [main CI run](https://github.com/liyafly/OpenCCForSigil/actions/runs/36013930134)
passed all native payload jobs, cross-platform Jieba comparison, package build,
and six runtime smoke jobs at commit
`a2696a52a412e9d2be1f065a8dc61834e3d4388e`. The [tagged release run](https://github.com/liyafly/OpenCCForSigil/actions/runs/36015654873)
at the same commit passed all of those jobs, generated provenance attestations,
verified them, and published this Release. The downloaded Release assets also
passed `tools/release_assets.py`, SHA-256 verification, and independent
attestation verification for all eight files. These checks do not establish
acceptance inside a real Sigil process.

Verify downloaded checksums with `tools/release_assets.py` and verify each
artifact's provenance with:

```sh
for asset in OpenCCForSigil_*.zip SHA256SUMS.txt; do
  gh attestation verify "$asset" \
    --repo liyafly/OpenCCForSigil \
    --signer-workflow liyafly/OpenCCForSigil/.github/workflows/ci.yml
done
```

The SHA-256 of the published `SHA256SUMS.txt` is
`3543bef74d9770a17b7ed60946ddb33664e0a2df93fdee3ec3a927cd9632800e`.

## Remaining acceptance

Installation, conversion, save, and reopen have not been tested in real Sigil
hosts on macOS arm64, Windows x64, or Linux x86_64. All host acceptance remains
**Not verified**.
