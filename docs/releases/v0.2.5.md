used by Sigil's plugin process. The Fat Plugin covers the five CPython

generated source archives are not installable plugins.

## Changes

- Add versioned rules with protect, final-wording, pre-replacement, and
  post-replacement actions, using literal or regular-expression matching.
- Bundle the pinned regex engine for all six supported runtime targets. Regex
  rules run offline with time, hit-count, output-size, and zero-length guards.
- Add templates for author-credit protection, marker-delimited protection,
  contextual replacement, and horizontal-space cleanup.
- Use one conversion pipeline for the rule sandbox and book conversion. Changes
  map back to original XHTML locations, and dependent edits stay grouped.

## Automated validation

The tagged release workflow validates the six runtime identities, builds the
Fat Plugin and six platform ZIPs, runs package smoke tests on all targets,
verifies SHA-256 checksums, and attests every release asset before publishing.
The ZIPs include the multilingual rule guide and third-party notices.

## Remaining acceptance

Installation, conversion, save, and reopen have not been tested in a real
Sigil host. Host acceptance remains **Not verified**.
