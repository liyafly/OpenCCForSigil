used by Sigil's plugin process. The Fat Plugin contains five CPython
3.14/cp314 runtimes; Linux x86_64 with CPython 3.12/cp312 has its own package.

## Changes

- Add a unified conversion setup flow with clear file-scope controls,
  conversion-direction selection, and a localized summary before analysis.
- Add a one-step, undoable action for resolving all remaining preview rows,
  while keeping manual decisions and selected file scope intact.
- Improve rule scopes, version-specific matching, conflict review, ownership
  handling, and import/export support for TSV, CSV, and JSON rule files.
- Improve profile and history search, profile comparisons, localized status
  filters, and keyboard-accessible preview details.
- Reduce repeated planning and preview work on large books while preserving
  source spans, atomic groups, and existing conversion output.
- Standardize visible terminology across English, Simplified Chinese, and
  Traditional Chinese. Recovery notices now use the localized default-profile
  name.

## Automated validation

The release candidate passed `make check`; the tagged workflow builds and
validates the Fat Plugin and six platform packages, runs the six runtime smoke
jobs, verifies package checksums, and attests release assets before publishing.
Real-Qt workflow checks and three-language preview screenshots are recorded in
the implementation evidence. These checks do not run the plugin inside Sigil.

## Remaining acceptance

Installation, conversion, save, and reopen in a real Sigil host have not been
tested for this version. Host acceptance remains **Not verified**.
