used by Sigil's plugin process. The Fat Plugin covers the five CPython
3.14/cp314 targets; Linux x86_64 with CPython 3.12/cp312 has its own platform
package.

generated source archives are not installable plugins.

## Changes

- Add stable-ID rule search, applicability filters, full-text details, and
  explicit handling for unfinished editor drafts.
- Make the rule manager fit ordinary screens, keep the table usable, collapse
  advanced settings and sandbox content, and keep save controls reachable.
- Show empty replacement targets as deletions and make whitespace-only targets
  visible while preserving their stored values.
- Preserve ruleset persistence and rule ownership/semantics during editing;
  keep import/export semantics, per-occurrence preview decisions, and sandbox
  hit/stage reporting accurate.
- Enforce output budgets for source, pre-, and post-replacement rules.
