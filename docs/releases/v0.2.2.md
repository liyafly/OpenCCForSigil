# OpenCCForSigil v0.2.2

## Changes

- Preserve the author-credit markers `◎著`, `◎ 著`, and `◎　著` in `tw2sp` and
  `tw2sp_jieba`, in addition to the existing `◎【著】` form.
- Keep bare `著` subject to normal conversion when no identifying marker is
  present, so ordinary text such as `慰藉著` still converts to `慰藉着`.
- Explain these cases in the localized Rules / sandbox help and the bundled
  multilingual rule guide.

## Automated validation

The release workflow builds and validates all platform packages, runs their
smoke checks, verifies release asset checksums, and publishes provenance
attestations before creating the GitHub Release.
