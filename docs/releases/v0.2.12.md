# OpenCCForSigil v0.2.12

## Install

Choose a ZIP below and install it through Sigil's plugin manager. The Fat
Plugin contains the five CPython 3.14/cp314 runtimes. Linux x86_64 CPython
3.12/cp312 has a separate package. GitHub source archives are not installable
plugin packages; each package requires its listed CPython ABI.

## Changes

- Keep the `*` direction when updating an existing wildcard rule.
- Recreate an empty `default` rule set if the last rule set is deleted after
  `default` was renamed.
- Report zero-width regex skips inside decoded numeric character references.
- Show the final result only once on the rule Test page.
- Align the rule guide and restore the required cancelled-unchanged status key
  in artifact validation.
