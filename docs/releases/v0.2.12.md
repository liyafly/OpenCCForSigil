# OpenCCForSigil v0.2.12

## Install

Choose a ZIP below and install it through Sigil's plugin manager. The Fat
Plugin contains the five CPython 3.14/cp314 runtimes. Linux x86_64 CPython
3.12/cp312 has a separate package. GitHub source archives are not installable
plugin packages; each package requires its listed CPython ABI.

## Changes

- Keep the `*` direction when updating an existing wildcard rule.
- Recreate an empty `default` rule set if the last rule set is deleted after
  `default` was renamed.
- Report zero-width regex skips inside decoded numeric character references.
- Show the final result only once on the rule Test page.
- Align the rule guide and restore the required cancelled-unchanged status key
  in artifact validation.

## Automated validation

- Local repository gate: `make check` — **868 passed, 1 skipped**.
- Real-Qt acceptance: **13/13** at the requested 960×640 window size.
- The tagged workflow builds and verifies native payloads for all supported
  runtimes, assembles the Fat Plugin and six platform ZIPs, runs all six
  package-smoke jobs, verifies checksums and attestations, and publishes only
  after those gates pass. Real Sigil host testing is a separate acceptance.

## Remaining acceptance

- Installation, conversion, preview acceptance, rule save, history, EPUB save
  and reopen in a real Sigil host: **Not verified** until performed on the
  published asset.
- Platforms not recorded as tested above remain **Not verified**.

Windows on Arm is not native support. The x64 package is only a candidate for
Windows 11 on Arm with x64 Sigil and x64 plugin Python; mark it **Not verified**
until tested on a physical device. Windows 10 on Arm cannot run x64 Sigil.
