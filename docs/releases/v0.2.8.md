## Changes

- Filter preview decisions by status, file, change category, risk, rule source,
  and literal source/target text. Filtering never changes the global pending
  count or reruns conversion.
- Undo and redo preview decisions, including group and bulk operations, and
  restore a decided change or group to pending. This history applies only
  before the EPUB is written.
- Browse frozen-plan diagnostics by file and code. Select a diagnostic to view
  its original line, column, and nearby source; related diagnostics select a
  real change, while no-change diagnostics remain read-only.
- Keep rule-occurrence groups distinct from cross-resource language-tag groups,
  protect MathML identifiers, and confirm when a filtered action affects hidden
  members of an atomic group.
- Index preview groups and compact bulk decision history for large previews.

## Automated validation

The tagged workflow publishes these assets only after all six platform package
smoke jobs, version/checksum validation, and asset attestations pass. The
release candidate also runs the full `make check` gate. Local three-language
Qt checks used Sigil's bundled Python/PySide6 on macOS; this did not load the
plugin inside the Sigil host.

## Remaining acceptance

Installation, conversion, save, and reopen in a real Sigil host have not been
tested for this version. Host acceptance remains **Not verified**.
